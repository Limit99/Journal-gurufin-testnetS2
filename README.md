## 📖 What is Gurufin?

Gurufin adalah platform Web3 yang memudahkan siapa saja untuk memulai perjalanan di dunia blockchain.

**Fitur Season 2:**
- ⛏️ Mining Mini-Game — Tambang gem setiap hari untuk memaksimalkan
- 💰 GXUSD Rewards — Stablecoin nyata sebagai hadiah
- 🔄 Swap & Burn — Tukar & bakar token untuk G-Points
- 📅 Daily Check-in — Bonus harian untuk pengguna aktif
- 🌍 Multi-currency — GXIDR, GXKRW, GXJPY, GXEUR, GXPHP

## ⛏️ Mining Mini-Game Tips

Hal-hal yang sudah aku pelajari dari mining mini-game:

- ✅ Login setiap hari untuk streak bonus
- ✅ Waktu terbaik mining: sore hari coba jam 15.35 untuk waktu indonesia
- ✅ Jangan skip daily check-in agar maksimal
- 🔄 Masih bereksperimen agar dapet eksplor strategi terbaik...

## 💰 GXUSD Rewards — What I Know So Far

- GXUSD = Stablecoin dari Gurufin
- Nilai   = Dipatok ke USD
- Cara dapat = Mining di aplikasi GURUFIN
- Kegunaan   = Swap, Burn jadi G-Points

Note: G-Points digunakan untuk naik rank Leaderboard atau beli ticket raffle mingguan dg cv 10P/tiket

## 📝 Notes & Lessons Learned

### ✅ Yang Sudah Aku Pelajari
- Mining mini-game simple tapi rewarding
- GXUSD rewards nyata, bukan janji kosong
- Swap GXUSD ke FX token (GXIDR,GXJPY,dll)
- Menukarkan FX token ke G-Points
- Konsistensi harian > grinding sesekali d discord

### 🤔 Yang Masih Aku Pelajari
- Cara maksimalkan penggunaan G-Points
- Strategi mining yang terbaik supaya chance ke gold/berlian lebih besar
